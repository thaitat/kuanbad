# ก๊วนแบด (PWA) — วิธีติดตั้งบน Android

## ไฟล์ในโฟลเดอร์
- index.html            ตัวแอป (แก้ค่าต่างๆ ได้ที่ "ส่วน C" ในไฟล์)
- manifest.webmanifest  ชื่อแอป ไอคอน สี
- sw.js                 ทำให้แอปเปิดได้โดยไม่ต้องต่อเน็ต
- icons/                ไอคอนแอป
- .nojekyll             ไฟล์ว่างสำหรับ GitHub Pages (ห้ามลบ)

## ขั้นที่ 1: นำขึ้นเว็บด้วย GitHub Pages (ฟรี ทำครั้งเดียว)
1. สมัครบัญชีที่ github.com
2. กด + มุมขวาบน > New repository ตั้งชื่อ เช่น kuanbad เลือก Public แล้วกด Create repository
3. กดลิงก์ "uploading an existing file"
4. แตกไฟล์ zip บนคอม แล้วลากไฟล์และโฟลเดอร์ทั้งหมดข้างในไปวาง (ต้องมี index.html อยู่ชั้นนอกสุด)
5. กด Commit changes
6. ไปที่ Settings > Pages > Branch เลือก main และ / (root) แล้วกด Save
7. รอ 1-2 นาที รีเฟรชหน้า จะเห็นลิงก์ เช่น https://ชื่อผู้ใช้.github.io/kuanbad/

## ขั้นที่ 2: ติดตั้งบนมือถือ
1. เปิดลิงก์ด้วย Chrome บนมือถือ ตอนนี้ต้องต่อเน็ต
2. รอให้หน้าแอปโหลดเสร็จ ประมาณ 5 วินาที
3. กดเมนู ⋮ มุมขวาบน > "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
4. กดติดตั้ง ไอคอนก๊วนแบดจะอยู่บนหน้าจอหลัก

## ขั้นที่ 3: ทำให้ใช้งานได้โดยไม่ต้องต่อเน็ต
1. หลังติดตั้ง เปิดแอปจากไอคอน 1 ครั้งตอนที่ยังต่อเน็ตอยู่ แล้วปิด
2. ทดสอบ: เปิดโหมดเครื่องบิน แล้วเปิดแอปจากไอคอน ถ้าหน้าแอปขึ้นตามปกติ แปลว่าพร้อมใช้ออฟไลน์แล้ว
3. หลังจากนี้ใช้งานในสนามได้เลยแม้ไม่มีสัญญาณ ข้อมูลทุกอย่างบันทึกในเครื่อง

หมายเหตุ: ตอนออฟไลน์ครั้งแรกๆ ฟอนต์อาจเป็นฟอนต์ของเครื่องแทน ใช้งานได้ปกติทุกอย่าง

## การดูแลข้อมูล
- ข้อมูลอยู่ในมือถือเครื่องที่ใช้ ไม่ได้อยู่บน GitHub
- สำรองหลังปิดวันเล่นทุกครั้ง: ตั้งค่า > สำรองเป็นไฟล์ (ส่งเข้าไลน์หรือไดรฟ์ของตัวเองได้)
- ย้ายเครื่อง: ติดตั้งในเครื่องใหม่ แล้วใช้ ตั้งค่า > กู้คืนจากไฟล์
- ห้ามล้างข้อมูลเว็บไซต์ของ Chrome หรือถอนการติดตั้งแอป ถ้ายังไม่ได้สำรอง

## อัปเดตแอปในอนาคต
1. แก้ index.html แล้วอัปโหลดทับใน repository เดิม (Add file > Upload files)
2. เปิด sw.js แล้วเปลี่ยน kuanbad-v2 เป็น kuanbad-v3 (เลขถัดไปทุกครั้ง) อัปโหลดทับด้วย
3. บนมือถือ เปิดแอปตอนต่อเน็ต 1-2 ครั้ง จะได้เวอร์ชันใหม่ ข้อมูลเดิมยังอยู่ครบ
